What I Have Learned

I've learned how to create a basic webpage using HTML. I've also learned how to create headings, paragraphs, lists, and links.

What I Learned From Lab 03

In Lab 03, I learned how to use CSS to change the appearance of an HTML webpage. I figured out how to connect an external CSS file to my HTML file and use CSS to change colors, fonts, and other parts of the page.

What I Learned From Lab 05

I learned mainly how to change website usability and accessibility. I learned how to use semantic HTML elements to improve the structure and meaning of a webpage.

Best Design Practices

I learned that best design practices include using a consistent layout, using appropriate colors and fonts, and making sure the website is accessible to all users. I also learned that it's important to test the website on different devices and browsers to ensure it works properly for everyone.
