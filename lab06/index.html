What I Learned From Lab 03

In this lab, I learned how to use CSS to change the appearance of an HTML webpage. I learned how to connect an external CSS file to my HTML file and use CSS to change colors, fonts, and other parts of the page. I also learned about ID selectors and class selectors and how they can be used to style specific parts of a webpage.

What I Learned From Lab 05

In Lab 05, I learned how to evaluate a website's usability and accessibility. I looked at how the CCBC website is organized, how easy it is to navigate, and how accessible it is for different users. I also learned that accessibility checkers can help identify problems that might make a website harder for some people to use. I had trouble getting the assigned checker to work, so I used another accessibility checker and included screenshots of the results. This lab helped me understand why testing a website and making it accessible are important parts of web design.

Best Design Practices

I learned that good web design should make a website easy to use and understand. Using clear headings, readable fonts, good color choices, and simple navigation helps people find information. Websites should also work well on phones and computers. I learned that checking a website on different screen sizes and testing accessibility can help make it better for everyone.
